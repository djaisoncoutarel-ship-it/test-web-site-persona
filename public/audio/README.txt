============================================
 BENEATH THE MASK — AUDIO LOCAL
============================================

1. Déposez votre fichier audio dans ce dossier, nommé exactement :

       beneath-the-mask.mp3

2. Rechargez le site : le lecteur basculera automatiquement
   sur votre fichier (badge "MP3" dans la barre de lecture).

Chaîne de sources (par priorité) :
  1. YouTube  → piste officielle (en ligne uniquement)
  2. MP3      → ce fichier (100 % local)
  3. SYNTH    → moteur lo-fi jazz Web Audio (100 % local, intégré)

Le mode SYNTH et le Mode Pluie ne requièrent AUCUN fichier :
tout est généré en direct par la Web Audio API du navigateur.
